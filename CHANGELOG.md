# Changelog

## 1.0.0 — 2026-09-12
First public release.

- Two-stage Windows Toast alerts for Hermes dangerous-command approvals:
  - Stage 1 (instant): risk category translated via a static EN→CN map of
    all 60 built-in `DANGEROUS_PATTERNS` / `HARDLINE_PATTERNS` rule names,
    plus the raw command. Alarm sound + 15s console beep loop until resolved.
  - Stage 2 (async): plain-Chinese command breakdown (what it does / risk
    verdict) generated by the user's active main model, read fresh from
    `config.yaml` per call. Silently skipped on LLM failure or if the
    approval was already resolved / superseded.
- Toast XML properly escaped — commands containing `<` / `&` no longer
  silently break notifications.
- Stage 2 routes through `agent.auxiliary_client.call_llm` with explicit
  base_url/api_key instead of `PluginLlm`'s auto chain, which misroutes and
  401s on OpenAI-compatible relay endpoints.

### Internal history
- 0.2.0 — Chinese explanations added (two stages, static map + LLM).
- 0.1.0 — alarm toast + beep loop only.
